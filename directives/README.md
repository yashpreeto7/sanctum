# Directives

SOPs (Standard Operating Procedures) written in Markdown.

Each directive defines:
- **Goal**: What the task accomplishes
- **Inputs**: What data/context is needed
- **Tools/Scripts**: Which `execution/` scripts to use
- **Outputs**: Expected deliverables
- **Edge Cases**: Known failure modes and how to handle them

## Naming Convention

Use descriptive, snake_case filenames:
- `scrape_website.md`
- `generate_report.md`
- `sync_google_sheets.md`

## Template

See `_template.md` for the standard directive format.
